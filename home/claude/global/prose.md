## Prose

Try to follow ASD-STE100 (Simplified Technical English) in all prose: code
comments, commit messages, documentation and replies.

- Write short sentences. Keep them under 20 words.
- Write one idea per sentence.
- Use the active voice. Name who does the thing.
- Use the present tense.
- Use the simplest word that is still accurate. Use the same word for the same
  thing every time.
- Do not use idioms, irony or long subordinate clauses.

The goal is prose a tired reader can parse on the first pass, and a
non-native speaker can parse at all.
